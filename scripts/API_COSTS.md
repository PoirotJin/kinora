# API 费用账本

价格文件位于动作数据根目录 `review/api_prices.json`。不附带任何供应商官方价格，管理员必须按实际账户、区域、模型、缓存计费规则填写；没有价格时显示未知，不能当作免费。

格式示例（`null` 是待填写占位，必须换成实际非负数才有效）：

```json
{
  "version": "your-tariff-2026-09-24",
  "prices": [
    {
      "provider": "",
      "model": "your-exact-response-model-id",
      "kind": "chat",
      "currency": "CNY",
      "input_per_million": null,
      "cached_input_per_million": null,
      "output_per_million": null
    }
  ]
}
```

模型、供应商、调用类型必须精确匹配；已有调用未记录供应商时 provider 留空。输入单价仅用于未缓存输入，缓存单价用于缓存命中输入，输出独立计价。如果缓存输入数未返回且缓存价不同，则该请求金额未知。输入/输出分量缺失也不能通过总 token 猜测金额。Embedding 通常只收输入费，仍需明确填写输出单价（按真实计费规则）。

新事件记录用户名、用途、任务 ID、供应商、缓存输入数、单价版本和调用时冻结的估算金额。`billed_to(username, path, purpose='', job_id='', provider='')` 向下兼容。它不保存提示词、API key 或客户端订阅凭据。价格配置错误不会中断原有请求结果，费用标为未知。

已有历史事件缺少当时价格，只能在查询时按当前配置作**历史估算**，并与新事件冻结金额区分。新事件当时价格未知的金额不会因为后来修改配置被静默改写。所有估算均非供应商结算账单，未覆盖其他应用、税费、阶梯/批量折扣等。币种分别合计、不擅自换汇。额度 admission/settlement 不变。

监控最多汇总最近 20,000 次事件，并沿用只读查询超时；超限明确标注非全历史总额。金额未知的请求数单独展示。UI 可按模型、类型、用途、用户、任务查看构成（前 200 个分组）。本地 Agent 重写没有服务器重写 API 账单，其订阅账单不会伪装成零费用；其后如有向量 API 等请求则仍计入对应类型。

另有独立的**累计已记录用量按当前单价的参考范围**：使用小型 `totals` 累计表，不受最近 20,000 条事件明细限制。缓存输入无法还原时，展示全部缓存命中到全部未命中的价格范围，输入和输出构成分别列出。它不还原历史价目变更，不包含未知用量请求的额外费用，也不是冻结账本的累计实付总价。按模型精确匹配 `provider: ""` 的价格项；相同模型可能来自多个供应商时，不应配置这种汇总参考价。

自动后台调用可使用 `with attributed_call('prompt_generation', 'dashscope'):`（Embedding 用途为 `embedding`）填入缺失归属。这会保留外层 `billed_to` 已明确指定的用途、供应商和任务 ID。为嵌套处理调用切换用途时，请显式使用新的 `billed_to` 上下文。
