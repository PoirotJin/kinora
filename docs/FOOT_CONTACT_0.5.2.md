# 服务端 0.5.2：转弯拼接脚部漂移修复

本次仅发布服务端修正。桌面客户端保持 0.5.1，Gadget 保持 0.15.2，未部署生产服务。

## 改动

四阶段拼接增加交替落脚约束：支撑脚固定，摆动脚抬起后落到下一目标位置；脚踝与脚趾保持刚性几何关系。脚部约束同时携带的骨盆高度和朝向与路径约束一致，避免互相覆盖。仍由 Kimodo 生成动作，不直接改写输出关节轨迹。

原有脚漂移检测方法和 8 cm 告警阈值保持不变。现在超限或无法评估支撑区间的候选会被隔离，不作为正常完成结果发布。朝向、接缝、根轨迹及选区外数据保持不变的检查继续执行。落脚策略代码也纳入缓存身份和精确代码验收，升级后必须重新验收。

原右转案例在相同源动作、选区、种子和检测方式下，指标降低约 68%。这是一组可复现工程对照，不是统计显著性或零滑步声明。五个拼接案例均通过原有朝向和接缝检查，没有步态告警；修复及拼接均保持选区外数据逐位不变。另完成真实生成和局部修复，共 7 个 GPU 案例。

159 项完整回归通过（包含首次启动测试及 2 项新增落脚/隔离测试）。最终小幅调整后另有 8 项定向复验通过，两组计数有重叠。所有 GPU 验收涉及的 10 个代码摘要与最终发布源码一致。[查看机器可读证据摘要](FOOT_CONTACT_0.5.2.json)。

测试使用独立目录、已安装计算环境与授权模型，未修改生产服务或用户动作。检测是人体关节代理指标，不能证明真实脚底接触、任意转弯都成功或真机安全。原技术报告的 0.5.1 基准仍然有效，本修复不覆盖其历史结果。

## 升级与验收

下载并解压 `kinora-server-0.5.2.zip`，按 [部署指南](SELF_HOSTING.md) 配置自己的环境。在切换自己的服务前运行：

```bash
.kimodo-venv/bin/python scripts/validate_kimodo_edit.py \
  --extended --output runtime/edit-acceptance-0.5.2 --gpu-root runtime/farm
```

只有命令成功退出、收据 `passed` 为 `true` 且代码摘要匹配时，才按部署指南安装自己的 `edit-ready.json`。旧版验收收据不能启用新版编辑。保留旧源码及数据备份，候选失败时查看隔离报告，不手写通过状态。
