# 版本与发布范围

## 1.0.0-beta.4 / 1.0.0-beta.3 预发布

| 组件 | 预发布版本 | 内容 |
| --- | --- | --- |
| macOS 桌面测试版 | 1.0.0-beta.3 | Universal DMG (`kinora-v1.0.0-beta.3`) |
| Ubuntu 桌面测试版 | 1.0.0-beta.3 | amd64 DEB (`kinora-v1.0.0-beta.3-ubuntu`) |
| 服务端源码测试版 | 1.0.0-beta.4 | 完整服务端源码、部署模板、计算队列与验收脚本；内含 Gadget 0.9.1 (`kinora-v1.0.0-beta.4-server`) |

当前预发布独立于稳定更新通道（`latest.json` 当前仍为稳定线）。服务端 `1.0.0-beta.4` 修复多镜头视频分段拼接与质量提醒、放宽地面/交互动作的提示词受理、为存在轻微接缝/几何提醒的编辑/场景/拼接任务保留可预览候选，并包含 Gadget 0.9.1。桌面端保持 `1.0.0-beta.3`（包含统一多标签工作区、视频动作提取隔离、个人资产快照批量导出、机器人编辑失败头指针自动回退、编辑与场景结果重定向）。

## 稳定版基线

| 组件 | 稳定版本 | 内容 |
| --- | --- | --- |
| 桌面客户端 | 0.7.0 | macOS、Windows、Linux 稳定安装包 |
| 服务端源码 | 0.5.2 | 稳定服务端、独立人体骨架、计算队列、部署和验收工具；含 Gadget 0.15.2 |
| 独立 Gadget | 0.15.2 | CLI / MCP 工具与断线恢复 |

稳定服务端源码为 `kinora-server-0.5.2.zip`，位于 `kinora-server-v0.5.2` Release；测试服务端源码为 `kinora-server-1.0.0-beta.4.zip`，位于 `kinora-v1.0.0-beta.4-server` Release。GitHub 自动生成的 Source code ZIP 只包含下载入口仓库，请使用命名的服务端 ZIP。

0.5.1 起服务端将人体骨架替换为 Kinora 独立数值定义，预览使用程序化骨骼和关节，不再下载外部人体骨架、蒙皮或纹理。新动作携带自身骨架信息；无内嵌骨架的动作从其存储坐标与旋转恢复并校验骨长。不一致的数据明确拒绝，不会静默改写原件。旧生成任务不会自动转为当前模型重新执行。

生成、修复、拼接使用 Kimodo；完整部署仍需授权模型、CUDA 和机器人资产。运行条件及验证范围见 [部署指南](SELF_HOSTING.md) 与 [发布验证](RELEASE_VALIDATION.md)。桌面安装包未公证或代码签名。自有代码按 Apache-2.0 授权，第三方遵循各自许可。
