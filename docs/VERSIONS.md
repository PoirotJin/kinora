# 版本与发布范围

| 组件 | 当前版本 | 内容 |
| --- | --- | --- |
| 桌面客户端 | 0.5.1 | macOS、Windows、Linux 安装包 |
| 服务端源码 | 0.5.2 | 完整服务端、独立人体骨架、计算队列、部署和验收工具；含 Gadget 0.15.2 |
| 独立 Gadget | 0.15.2 | CLI / MCP 工具与断线恢复 |

当前源码为 `kinora-server-0.5.2.zip`，位于 `kinora-server-v0.5.2` Release。0.5.1 源码作为历史基准保留；桌面安装包保持 0.5.1。GitHub 自动生成的 Source code ZIP 只包含下载入口仓库，请使用命名的服务端 ZIP。

0.5.1 服务端将人体骨架替换为 Kinora 独立数值定义，预览使用程序化骨骼和关节，不再下载外部人体骨架、蒙皮或纹理。新动作携带自身骨架信息；无内嵌骨架的动作从其存储坐标与旋转恢复并校验骨长。不一致的数据明确拒绝，不会静默改写原件。旧生成任务不会自动转为当前模型重新执行。

生成、修复、拼接使用 Kimodo；完整部署仍需授权模型、CUDA 和机器人资产。运行条件及验证范围见 [部署指南](SELF_HOSTING.md) 与 [发布验证](RELEASE_VALIDATION.md)。桌面安装包未公证或代码签名。自有代码按 Apache-2.0 授权，第三方遵循各自许可。

0.5.2 服务端修复转弯拼接脚部漂移，并将原 8 cm 告警阈值作为失败隔离条件。[改动与实测](FOOT_CONTACT_0.5.2.md)。
