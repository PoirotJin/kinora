# 0.5.1 服务端发布验证

验证日期：2026-11-09（北京时间）。桌面 0.5.1 安装包未修改。Gadget 0.15.2 更新格式说明与版本标识，协议行为不变。本次验证针对独立人体骨架的服务端补丁。

## 实际通过的检查

- 156 项核心回归：骨架定义、旧数据骨长恢复、预览高度、转换、修复、拼接、导出、推理缓存、机器人编辑、网格 FK、动力学、权限和账号路径。
- 49 项 Gadget 协议与恢复测试。
- 全新源码包解压，清单校验和首次启动测试通过：创建账号、登录改密、目录和预览、Gadget 下载；未安装模型时明确拒绝生成。
- 真实 CUDA 生成预检，以及 source、repair、splice-straight、splice-turn 四个案例通过。修复与拼接检查选区外原件不变、数值连续性和接缝。
- 独立人体骨架生成的动作实际完成 G1 30 帧重定向，输出形状与有限性检查通过。这是求解链路验证，不代表任意动作均能通过动力学。
- G1 3600 帧精修正例进入 ready，悬空反例进入 quarantined；未接受候选不可导出，权限、撤销/重做、原件及选区外帧保护通过。
- `doctor --full` 通过；29 个官方 G1 文件按固定哈希检查。人体描述文件随源码分发，可离线重新生成，无外部人体资产。

## 环境与限制

Linux x86_64，Python 3.10，48 GiB NVIDIA GPU，PyTorch 2.5.1 / CUDA 12.4，MuJoCo 3.4.0，Node 22.16.0。测试在隔离临时目录执行，复用已安装计算运行时与授权权重，未切换生产服务或用户数据。新解压启动测试也复用已安装 Python 依赖，不宣称重新下载所有环境与模型。

外部 SMTP、付费 API、TMR、私有机器人与真机控制未在本次实跑。G1 精修正例使用合成平衡姿态与手臂动作，不能作为真实机器人安全认证。存量无内嵌骨架的数据需在升级副本中验证预览与导出；旋转和坐标不一致的数据会明确报错。

精确分发文件及 SHA-256 见包内 `SOURCE_MANIFEST.json`，运行 `python scripts/verify_source.py` 验证。
